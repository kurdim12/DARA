# Visual pass — 15 Sep 2026

The facelift shipped the structure; this pass fixed how it looked. The
equivalents from the day before are in `../facelift/`, same file names, so the
two folders diff screen by screen.

What changed, in order of how much it mattered:

1. **The real mark.** `public/brand/dara-mark.png` — the brush-stroke درع, the
   same artwork the installed app already shows on a phone's home screen — is
   in the hero. It was a generic SVG shield with a letter D in it.
2. **The hero has depth.** A navy gradient and one soft light instead of a flat
   slab with two stray circles.
3. **Type has hierarchy.** Section headings went 17 → 20/800 and the hero 30 →
   33 with tighter tracking, so a heading no longer reads the same as a row
   title one line below it.
4. **The verdict runs edge to edge** at 34/800, and the reasons are numbered to
   match the superscripts inside the message. Three identical warning icons
   said nothing about which mark they belonged to.
5. **Fixed two things that read as broken**: tiles whose titles sat at
   different heights, and a disabled primary button in pale blue with white
   text on it.
6. **The page ground is a few points deeper**, so a white card has an edge.
